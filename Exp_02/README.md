# Experiment 02 – Basic Flutter Hello World App

## Aim
To create and run a basic Hello World application using Flutter.

## Requirements
- Flutter SDK
- Dart SDK
- VS Code / GitHub Codespaces
- Web browser

## Procedure
1. Created a Flutter project using Flutter.
2. Modified `lib/main.dart`.
3. Added a Hello World message.
4. Installed project dependencies using `flutter pub get`.
5. Built the application for Web using `flutter build web`.
6. Ran the Web application using a local web server.
7. Verified the output in the browser.

## Result
The basic Flutter Hello World application was successfully created, built, and executed in the browser.
